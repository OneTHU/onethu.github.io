01

为什么是 OneTHU

清华的校园服务分散在十几个系统中，登录方式、界面与账号状态各自独立。OneTHU 把它们整合为一套：一个身份、一份数据、一套界面，三端一致。

一个身份

登录一次，全校通行；登录状态过期后自动恢复，无需重新登录。

处处一致

所有页面使用同一份数据与同一套界面、配色；同一个对象在各页面共用同一个原子。

一个对话入口

OneTHU Harness（AI Agent）：用一句话查询作业、课表、电费、图书馆预约与学校新闻；Agent 常驻左下角。

数据可靠

只读取校方公开接口；数据未取到时如实显示，不会提前标记为已提交。

全平台

macOS / Windows / Android 功能对齐：通知、小组件与下载位置在三端均可用。

功能总览

十二组能力，覆盖登录、学习、生活、通知与扩展；每一项都对应应用内的真实入口。

统一身份与数据层

登录一次即可使用全部模块：网络学堂、信息门户、图书馆与校园卡共用同一次登录，支持二次验证。登录状态过期后自动恢复，弱网或应用挂起后无需重新登录。

  • 一次登录 · 全模块共用登录状态
  • 二次认证（2FA）· 账号凭据本地加密
  • 登录状态自动维持 · 支持登录凭据导出与导入
内核

网络学堂全景

课程、作业、通知、文件与讨论区集中管理；截止时间与提交状态均与学校系统保持一致，不会提前标记为已提交。

  • 课程详情 · 作业 / 通知 / 文件 / 分组 / 讨论区
  • 全局搜索（课程 / 作业 / 通知 / 文件）
  • 讨论区阅读与回复 · 附件下载
学习

外部作业源聚合

雨课堂、TUOJ（AI 版 / 经典版）、Tyche、DSA OJ 四个系统的作业统一汇总至「全部作业」与「今日」，在一个位置查看。

  • 仅汇总作业信息，不代为提交
  • 雨课堂题干在应用内完整渲染，公式与图片正常显示
  • 已批改的作业显示得分与教师评语；试卷不提供提交入口
雨课堂TUOJTycheDSA OJ

日程 · 课表 · 提醒

课表、云日历与自定义日程（含重复规则）合并为一条时间轴；提醒通过系统通知送达。

  • 三端系统通知（Windows / macOS / Android）
  • 静默时段内的提醒顺延至时段结束；若顺延后已晚于事件本身，作业截止提醒改在静默开始前发出，课程与考试提醒不再发送
  • 每日早报仅在当天有安排时发送
通知

桌面小组件（Android）

每块小组件可单独设置内容：日程与截止任务、单个原子（显示详情）、收藏夹图标组、1×1 快捷方式。

  • 五种初始形态：1×1 / 2×1 / 2×2 / 3×2 / 4×1
  • 图标组每格可独立点击；详情形态高度越大显示行数越多
  • 实时显示教室空闲情况与洗衣机剩余时长
小组件

原子化

页面、组件与校园数据（课程、作业、文件、通知、新闻、洗衣机、教室、场馆、图书馆）统一为“原子”：可搜索、可收藏、可通过链接直接打开，也可放置到桌面。

  • 全应用统一索引：页面、组件与校园数据同源
  • 收藏夹为可嵌套的原子面板
  • 寻迹：今日日程地图 · 地点标注 · 预计到达时间 · 一键前往
