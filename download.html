上手三步

01

安装并登录

使用清华大学统一认证账号登录，支持二次验证；登录一次后，网络学堂、信息门户、图书馆与校园卡共用同一次登录。

02

跟随首启导览

导览依次引导界面定制、账号接入（雨课堂 / OJ / 邮箱日历 / 云盘）与桌面小组件，每步均可跳过。

03

按需打开提醒与小组件

设置 → 通知：打开提醒、设置提前量与静默时段，并可运行自检；Android 还可在桌面添加小组件（1×1 快捷方式 / 图标组 / 详情）。

i

数据与许可

只读校方公开接口，仅供个人学习与日常使用。自有代码以 MIT 开源并 附两条限制（严禁商业用途；严禁用于对清华大学信息服务的攻击性访问），第三方组件按其自带许可，详见 LICENSE 与 第三方许可。

i

下载渠道

安装包同时发布在 GitHub Releases 与清华云盘（云盘镜像），两处为同一批文件；校内网络访问 GitHub 不畅时请使用云盘。

i

Android 升级须知

从 0.9.0 或更早版本升级需先卸载旧版再安装：本版更换了签名证书，覆盖安装会失败。卸载会清除本机登录状态与已填凭据，安装后需重新登录；仅此一次，从 0.11 起可正常覆盖升级。

i

数据异常的处理

使用页面右下角的刷新按钮重试；仍异常时可在 Issues 反馈，并附上设置页「自检」的结果。
