Start here

git clone --recurse-submodules https://github.com/smartThise/OneTHU.git
cd OneTHU
git switch dev3
git submodule update --init --recursive
pnpm install
pnpm dev

pnpm dev launches a quick browser preview for UI work; run inside the Tauri host whenever you need campus networking, credentials, local files, or skill IPC.
