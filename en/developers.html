Start here

git clone --recurse-submodules https://github.com/smartThise/OneTHU.git
cd OneTHU
git switch dev3
git submodule update --init --recursive
pnpm install
pnpm dev

A browser preview is not the native host: network, credentials, files and skill IPC need Tauri. See the build guide for platform commands.
