# 安装与上手

> 最后更新：2026-09-23 10:16

## 1. 安装

安装包发布在 [GitHub Releases](https://github.com/smartThise/OneTHU/releases/latest)，也可从 [官网下载页](https://onethu.github.io/download.html) 按平台获取。
校内网络访问 GitHub 不畅时，用 [清华云盘镜像](https://cloud.tsinghua.edu.cn/d/56f78a2a0b144a6ab737/)（与 Releases 同一批文件）。

| 平台 | 安装包 | 说明 |
|---|---|---|
| macOS | `.dmg` | Apple Silicon 与 Intel |
| Windows | `.exe` | x64 安装器（NSIS） |
| Android | `.apk` | arm64 与 universal；功能与桌面端对齐 |

macOS 首次启动若被 Gatekeeper 阻止，可在「系统设置 → 隐私与安全性」中放行；
Android 需在系统中允许安装未知来源应用。

!!! warning "Android 升级须知"

    从 0.9.0 或更早版本升级需先卸载旧版再安装：0.10.0 更换了签名证书，覆盖安装会失败。
    卸载会清除本机登录状态与已填凭据（含外部作业源），安装后需重新登录；仅此一次，
    从 0.11 起可正常覆盖升级。macOS 与 Windows 不受影响。

## 2. 登录

1. 使用清华大学统一认证账号登录，支持二次验证。
2. 登录一次后，网络学堂、信息门户、图书馆、校园卡等模块共用同一次登录，无需重复登录。

凭据仅保存在本机，不上传至第三方服务。

## 3. 首次使用建议

- **通知与提醒**：首次安装或导览结束后会申请通知权限；Android 13 及以上未授权时，
  提醒会静默失效。授权后可在「设置 → 通知」调整提前量与静默时段，并通过「诊断」
  核对系统侧状态。
- **桌面小组件（Android）**：可在桌面添加 1×1 快捷方式、图标组或详情卡片；倒计时与
  「正在上课」按当前时间原生重算，深色模式跟随系统。
- **首页卡片**：导览中可选择今日页保留的卡片；插件原子（课程、作业、场馆等）收藏后
  可固定在首页。
- **账号接入**：首启导览在界面定制之后提供四步接入——雨课堂、OJ 平台（Tyche 与 DSA OJ）、
  清华邮箱日历、清华云盘，每步均可跳过；凭据与「设置」中对应入口读写同一份，不另存一份。
- **桌面小组件（Android）**：导览末步可一键放置「今日日程」小组件；启动器不支持请求式放置
  时，界面给出「长按桌面 → 小组件 → OneTHU」的手动路径。导览有新内容时新旧用户都会再看
  一轮（当前为 `onethu.onboarded.v3`）。
- **外部作业源**：在「设置 → 外部作业源」登录雨课堂 / TUOJ / Tyche / DSA OJ，
  可将各平台截止时间合并进「全部作业」与「今日」。详见
  [作业区（聚合 / 忽略 / 提交）](homework.md)。

## 4. 数据异常的处理

| 现象 | 处理 |
|---|---|
| 列表为空或数据陈旧 | 使用页面右下角的刷新按钮重试 |
| 多次重试仍失败 | 在「设置 → 关于」导出日志，并附在 Issue 中 |
| 通知未触发 | 在「设置 → 通知」运行诊断，核对授权与排程状态 |
| 在线服务 / 体育页面无法打开 | 应用内打开失败会给出原因提示，并回落至系统浏览器 |

反馈时请附应用版本、平台与诊断结果，可显著缩短定位时间。反馈入口见
[交流与反馈](community.md)。

## 5. 开发者：本地运行

环境要求：Node ≥ 20、pnpm、Rust toolchain；Android 构建另需 Android SDK 与 NDK。

```bash
git clone https://github.com/smartThise/OneTHU.git
cd OneTHU
pnpm install                                  # 安装 workspace 全部依赖

pnpm dev                                      # 浏览器预览（Vite dev server）
pnpm --filter @onethu/desktop tauri:dev       # 原生桌面壳开发模式（前端热更新）
```

浏览器预览直连校园网接口受同源策略限制，涉及接口的验证请在原生壳中进行。
完整的构建、发布与提交前自检见 [构建与发布](build-and-release.md)。

!!! warning "使用边界"

    体育场馆模块**仅提供查询**（场馆 / 场次 / 余量 / 我的预约 / 退订），不提供应用内预约提交。
    严禁将本项目源码用于任何形式的自动预约、抢场或抢课。详见 [许可与致谢](license.md)。
