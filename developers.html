开始运行

git clone --recurse-submodules https://github.com/smartThise/OneTHU.git
cd OneTHU
git switch dev3
git submodule update --init --recursive
pnpm install
pnpm dev

浏览器预览不等于原生宿主：网络、凭据、文件和技能 IPC 需要 Tauri 环境。平台完整命令见构建文档。
