开始运行

git clone --recurse-submodules https://github.com/smartThise/OneTHU.git
cd OneTHU
git switch dev3
git submodule update --init --recursive
pnpm install
pnpm dev

pnpm dev 可在浏览器里快速调试界面；需要联调校园网络、凭据存储、本地文件与技能 IPC 时，请通过 Tauri 启动原生宿主。
